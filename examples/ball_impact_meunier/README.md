# Meunier-law ball-impact rerun

Uses the exact material package of main-text Figure 4, copied from
`../figure10_cann_csr/nn_cache/material.flat`.
Coarse and fine meshes are reused to isolate the change of constitutive law.
Both meshes were solved on 2026-10-07 using
`/home/guanjs/OpenRadioss-latest-20251211`, its GNU double-precision
Starter/Engine and `tools/userlib/examples/law291_userlib/libraduser_law291.so`.
Both Starter runs reported zero errors and zero warnings, and both Engine
runs terminated normally at 15 ms (3,065 and 4,351 cycles).

On a Linux host with the existing user library:

```bash
bash run_ball_wsl.sh all
MESH_SIZE=2.0 PREFIX=BALL_FINE bash run_ball_wsl.sh all
python3 postprocess_ball.py
```

Existing meshes are reused; GMSH is required only if a mesh is missing.
Override OPENRADIOSS_ROOT and GMSH for the host installation.
Do not reuse the original Treloar impact metrics or figures as Meunier results.

Postprocessing writes to `figs/meunier_ball_impact/` to preserve the old figures.

`ball_impact_metrics.json` stores response metrics and mesh differences.
`ball_impact_qa.json` stores energy checks and the invariant/Jacobian envelope
of saved animation frames, generated by `audit_ball.py`.
